# E-commerce RFM Customer Segmentation & CLV

Segment 2,500 customers of a fictional Indian e-commerce store into actionable
marketing groups using **RFM analysis** (Recency, Frequency, Monetary),
validate the segments with **K-means clustering**, and estimate **customer
lifetime value (CLV)** per segment to guide where marketing money should go.

## Problem statement

The store has ~12k orders but treats every customer the same: one generic
discount blast per festival. Marketing spend is wasted on one-time buyers who
never return, while the small group of high-value repeat customers — the ones
who actually pay the bills — gets no special attention.

**Goal:** identify *who* the valuable customers are, *who* is slipping away,
and *who* is already lost, then recommend a concrete action for each group.

## Dataset

`data/orders.csv` — **fully synthetic**, generated by `gen_data.py` (seed=42,
so it is reproducible):

| Column | Description |
|---|---|
| `order_id` | Unique order id (`ORD000001`…) |
| `customer_id` | Unique customer id (`CUST0001`…) |
| `order_date` | Order date, 2026-01-01 → 2026-09-30 |
| `amount_inr` | Order value in INR (category-dependent lognormal) |
| `category` | Electronics / Fashion / Home & Kitchen / Grocery / Beauty |

Scale: **12,081 orders × 2,500 customers × ₹3.90 Cr revenue**.
Customer behaviour is modelled on realistic archetypes: ~45% one-time buyers,
~30% occasional shoppers, ~15% regulars, ~7% loyals and ~3% whales (high spend,
high frequency). Order dates follow a growth trend (later months heavier).

## Methodology

1. **RFM features** — per customer, as of 2026-10-01:
   - *Recency*: days since last order · *Frequency*: order count ·
     *Monetary*: total spend (₹).
2. **Quintile scoring** — each dimension scored 1–5 with `NTILE(5)` window
   functions in SQL (`sql/rfm_queries.sql`); the Python script mirrors this
   with rank-based quintiles. Recency is inverted (5 = most recent).
3. **Segment assignment** — rule-based on the R/F/M scores, e.g. Champions
   (RFM total ≥ 14/15), Can't Lose Them (high value, gone quiet), At Risk,
   Loyal Customers, Potential Loyalists, New/Promising, Need Attention,
   About to Sleep, Hibernating, Lost.
4. **K-means cross-check** — `sklearn` K-means (k=4, scaled RFM, seed=42) to
   verify the rule-based segments line up with data-driven clusters.
5. **CLV estimate** — per segment:
   `CLV = avg order value × orders/month × lifespan (months)`,
   where lifespan = months between first and last order (floored at 1).

## Key findings

1. **Pareto on steroids** — Champions (440 customers, **17.6%** of the base)
   generate **₹2.76 Cr = 70.9%** of revenue. Champions + Loyal Customers
   (936 people, 37.4%) drive **87.8%** of all revenue.
2. **Whale economics** — a Champion's estimated CLV is **₹62,820**, roughly
   **30×** a Lost customer (₹2,077). Every rupee of retention budget earns
   the most when spent on the top two segments.
3. **₹13.7 L is slipping away** — 282 At-Risk + Can't-Lose-Them customers
   used to be high value but have gone quiet. A win-back campaign aimed at
   just these 11% of customers protects more revenue than any acquisition push.
4. **Acquisition is leaking** — 899 customers (**36%**) are Lost, Hibernating
   or About to Sleep, almost all one-time buyers; ~17% of the base never made
   a second purchase. Fix onboarding / first-to-second-order conversion before
   scaling ad spend.
5. **Segments are real, not arbitrary** — K-means independently rediscovers
   the same structure (one cluster is 73% Champions; another is 64% Lost
   one-timers), so the quintile cut-offs are not driving the result.

## Recommendations per segment

| Segment | Size | Action |
|---|---|---|
| Champions | 440 | VIP treatment: early access, personal offers, referral rewards. *Do not* discount heavily — they already buy. |
| Loyal Customers | 496 | Loyalty points / tiered rewards to nudge them into Champions. |
| Potential Loyalists | 156 | Cross-sell + bundle offers; they buy often but spend little per order. |
| New / Promising | 101 | Welcome series + second-order coupon within 30 days (kills the one-and-done leak). |
| Need Attention | 126 | Limited-time personalised offers; small nudge before they drift. |
| At Risk / Can't Lose Them | 282 | Win-back: "we miss you" + best-seller recommendations + support check-in. Highest ROI campaign. |
| About to Sleep / Hibernating | 477 | Low-cost re-engagement (email/SMS); suppress from expensive paid ads. |
| Lost | 422 | Let go — exclude from paid retargeting; keep only in cheap broadcast lists. |

## Tools used

- **Python**: pandas (RFM computation), scikit-learn (K-means), matplotlib (charts)
- **SQL**: CTEs + `NTILE()` window functions + conditional aggregation
  (`sql/rfm_queries.sql`, runs on SQLite / PostgreSQL)
- **Data**: synthetic, seeded (`numpy`, seed=42) — no real customer data

## How to run

```bash
cd ecommerce-rfm-segmentation

# (optional) regenerate the synthetic dataset
~/workspace/.venv/bin/python gen_data.py

# run the full analysis: prints insights, saves 3 charts to charts/
~/workspace/.venv/bin/python analysis.py

# run the SQL version (SQLite example)
sqlite3 rfm.db < sql/rfm_queries.sql   # after importing data/orders.csv as 'orders'
```

Outputs: `charts/segment_sizes.png`, `charts/monetary_vs_frequency.png`,
`charts/clv_by_segment.png`.

## Limitations / next steps

- Quintiles are row-based (`NTILE`), so with many one-time buyers the same raw
  frequency can span quintiles — standard behaviour, but value-based binning
  could be compared.
- CLV here is a simple historical estimate; a next step would be a
  probabilistic model (BG/NBD + Gamma-Gamma) and 6-month forward validation.
- With real data, join in acquisition channel and category affinity for
  segment-specific creative.
